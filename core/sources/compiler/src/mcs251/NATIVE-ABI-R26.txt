R26 实验原生调用约定（局部启用，不替换默认 ABI2）
================================================
编译参数: -mmcs251 --mcs251-native-abi
声明与定义: unsigned long f(unsigned long x) __reentrant __sdcccall(3);
跨文件必须使用相同声明；显式属性参与函数类型兼容检查。

首个参数和返回值:
  8 位: R7
 16 位: WR6，逻辑低字节 R7、高字节 R6
 32 位: DR4，逻辑低到高字节 R7/R6/R5/R4；float 保持原始位模式
第二个及后续参数保持原有可重入栈布局；调用者清理栈。
调用者在 SEND 写入原生寄存器前保存活跃值，返回值先取走再恢复寄存器。
完整对齐寄存器组可直接 MOV WR/DR；分散寄存器保留有依赖顺序的搬运。
三字节以上循环置换先 PUSH 剩余源字节、再逆序 POP 到目标；不会丢弃值。

支持范围:
普通 bank 0、内部栈、可重入函数的直接调用；8/16/32 位整数和 float 参数；
void 或上述标量返回。四种 small/large 与 stack-auto 组合均有板上定向测试。
明确的跨文件直接调用、嵌套新旧 ABI、递归、volatile 参数、XDATA 返回源、
以及常规 ISR 调用可重入原生函数已纳入本轮测试。

限制与拒绝:
原生间接调用、原生 ISR 入口、naked、非零寄存器组、callee-saves、banked、
xstack、可变参数、指针/聚合/64 位参数和返回均未开放；bit/_Bool 返回拒绝。
不使用全局 --sdcccall 3，不修改运行库调用约定。取函数地址并不自动获得
原生间接调用能力；可使用普通 ABI 包装函数。故意的不兼容强制转换不受保障。
原生符号加入 __m251r3_ 标记，旧 ABI 调用者/被调用者错配时链接失败。
普通未标注函数保持默认 ABI，关闭实验方案只需取消属性和开关后重新编译。

同时修复的通用问题:
1. SDCCicode.h 补充 isOperandVolatileOrAtomic 声明。
2. 无符号常量再结合按相同目标宽度构造有类型 literal，避免双精度中间值
   经无类型构造变为 float；不穿透不同宽度/符号及不同 _BitInt 宽度。
   实板复现: (i*0x01020305UL+0x89abcdefUL)+0x76543210UL 的 large 路径。
   原 R25 会错误生成 __fsadd，255/256 个专项输入失败；R26 已修复。

运行库保持 ABI2。本轮 892 个运行库 C 单元重编，20 个存档与 R25 完全相同。
51 个既有固件重编后 HEX 相同，引用校验过哈希的既有证据；不冒充本轮重跑。
实验 ABI 的新固件、无符号折叠专项和基准有新采集。
此原型尚非一般生产认证；完整范围和原始失败/恢复记录见 round26 报告。
