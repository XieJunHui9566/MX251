R35 / R36 binary32 位模式运行库

fsdiv_bits.c 来自本树 device/lib/_fsdiv.c 的 MCS251 分支，保留许可证与算法。
输入、输出改为 unsigned long 位模式；这是表示的迁移，不是浮点数值转换。
使用现有宽寄存器后端编译，再将全局 ABI4 符号
___m251r4___fsdiv_bits 改为 ___m251r4___fsdiv，重新汇编进独立 libnativefloat.lib。
两个 32 位参数为 DR4/DR12，结果为 DR4；不增加包装函数或运行时跳板。
不得将这个对象装入普通非 native 浮点库：旧入口及参数传递约定不同。

R36 新增 bits_eq/ne/lt/le.c 和 bits_u2f/s2f/f2u/f2s.c。
比较函数处理 NaN（关系比较及相等返回假，不等返回真）和正负零。
新编译器仅在 --mcs251-native-runtime 下保留浮点 <=/>=，调用 __fsle；
同时禁止将浮点自比较折叠为常量。旧配置、其它目标不自动改语义。
比较及转换的公开入口仍为 ABI2，构建器生成显式桥接；内部函数采用 ABI4。
_Bool 返回从 R7 搬到 DPL，首参从 A/B/DPH/DPL 搬到 DR4；比较的第二参数
从入口 SPX-6/-4 的两个字读取到 DR12，追加 ecall 前完成，不依赖硬编码内存地址。

构建入口：本实验轮次根目录 build_runtime.py，重编完整原生浮点库以匹配新前端。
使用入口：sdcc-native.py / sdcc-wide.py，支持 small/large + stack-auto。
现有标准库、其它目标、普通 small、非重入模型不自动替换。
R36 编译器包含 NaN 比较修复和无符号 32 位取负的宽后端表示；不能再使用 R35 编译器配新 <= 语义。

除法数学契约：binary32 最近偶数舍入，支持带符号零、次正规输入和输出、Inf、NaN。
首个 NaN 输入的载荷与符号保留，并设置 quiet 位；0/0 和 Inf/Inf 返回 7FC00000。
不读写 errno，不提供动态舍入模式或 IEEE 异常标志；不调用芯片数学加速器。
除法无静态工作区，栈帧 4 字节；新增八个整数位模式核心没有局部栈帧，桥接 ecall
仍占返回地址空间。调用方和 ISR 必须遵守对应 ABI 保存约定。

整数转浮点保持旧策略：幅值向上取相邻 binary32 值；有符号负数按幅值转换后加符号，
即不精确时远离零，不能称作最近偶数舍入。INT_MIN 通过无符号减法求幅值，避免 C 有符号溢出。
有效范围内浮点转整数向零截断。直接库调用的越界行为保留旧策略：无符号负值为零、
过大正值/正 NaN 为 FFFFFFFF；有符号转换先处理幅值再按模 2^32 恢复符号。
这些越界结果是库的兼容策略，不是标准 C 对越界浮点强转的保证。

R36 验证见 semantics-oracles.json、semantics-board-results.json 和 report.html。
本轮抽样及定向验证不等同于穷举所有 2^64 输入组合或完整 IEEE 754 认证。

R37：sqrt_bits.c 迁移同树 sqrtf.c 的 MCS251 整数递推到宽寄存器核心。
浮点入口保持 ABI4 的 DR4 参数和 DR4 返回，构建时仅重命名同表示符号为 sqrtf。
负非零实数（含负无穷）尾调用 sqrt_domain.c，按原库约定设置 EDOM 并返回正零；
该辅助函数由常规生成器访问模型对应的 errno。errno 是原库共享全局变量，
并未变成线程局部存储；ISR 测试显式保存和恢复它，不声称 errno 自身可并发隔离。
正负零、正无穷、所有 NaN 位模式原样返回（包括 signaling 位），不强制 quiet。
非负有限输入仍采用固定最近值舍入；二进制有理输入的非精确平方根不会恰好位于中点。
指数改存为无偏指数加 254，范围 105..381，避免有符号除法和移位，数学算法未改。
25 次主循环和至多 23 次次正规数规范化均有界；核心无局部栈帧。
编译器与 R36 字节一致；独立库新增 sqrt_domain.rel，并只替换 sqrtf.rel，
其余 61 个已有成员逐字节保持不变。详见本轮 report.html 和 sqrt-oracle.json。

R38：fsmul_bits.c 将原 _fsmul.c 的 C fallback 迁移到 binary32 位模式接口。
保留原正常数汇编快路径，入口及返回仍是 ABI4；仅改写慢路径的表示与代码生成。
四个 16x16 精确乘法通过 fsmul_u16.c 的 ABI4 入口复用常规生成器的 MUL WR 指令；
宽后端尚不直接导入这类乘法，辅助入口仅使用两个参数的低 16 位。
sign 与 lo 改为 32 位表示，lo 重组时仍显式截断到 16 位；避免字节提取中间指令回退，
不更改精确 48 位乘积、sticky 累积或最终一次最近偶数舍入。
特殊输入沿用首个 NaN payload/sign 并 quiet，0*Inf 返回 7FC00000，保留带符号零，
完整处理次正规输入/输出和上下溢出；不读写 errno，不提供 fenv 异常标志。
核心局部栈帧为 18 字节，调用辅助函数另有现场保存开销；未宣称总栈只有 18 字节。
编译器与 R37 字节一致。浮点库替换 _fsmul.rel 并新增 fsmul_u16.rel，
其余 62 个已有成员保持字节一致。详见本轮独立参考、实板测试与计时报告。

R42：fsadd_bits.c / fssub_bits.c 取代独立 native 浮点归档的旧加减法对象。
这次是边界正确性修复，不仅是表示迁移：旧库不完整处理 NaN/Inf/次正规数，
旧减法的 -((-a)+b) 还会把精确相消的正零翻为负零。
新加法按幅值排序，使用27位尾数（含guard/round/sticky），一次最近偶数舍入，
保留渐进下溢、带符号零、无穷；首个原始NaN保留符号和payload并quiet，
无效的无穷运算返回7FC00000。不读写errno，不提供动态舍入模式或fenv标志。
减法先保护第二个NaN的原始符号，再翻转第二操作数后调用完整加法，
并优先保留第一个NaN。NaN的payload选择是明确的库策略，不是IEEE唯一选法。
对齐距离>=27时尾数仅留sticky，其余最多26步；规范化最多26步，不使用64位库。
所有工作变量均为局部；加法局部帧16B，减法局部帧0B，不含调用保存和返回地址。
构建器只重命名同表示的ABI4符号为__fsadd/__fssub，DR4/DR12输入、DR4输出不变。
编译器二进制与R41相同。完整归档仍为64成员，仅这两个对象改变；
其余62成员保持字节一致。普通模型/非native库及MCS51路径不自动替换。
宿主算法参考、原库失败基线、两个stack-auto模型的实板结果及C251比较见R42记录。

R43：在特殊值处理后只保留结果符号及异号标记，幅值交换时翻转结果符号；
不再交换并长期保留两个原始32位输入。两个符号标记改用16位，指数先取高16位
再右移7位，舍入判定只检查低16位。最终指数打包的(ea-1)<<7最大为32384，
可在16位内完成；尾数和最终的加法进位仍是32位，未缩减有效数字或舍入位。
加法核心722B，局部帧2B；减法59B、局部帧0B不变，不代表总调用栈开销。
二进制编译器仍与R42相同，本轮完整归档仅_fsadd.rel改变。
字节符号表示试验触发现有GETBYTE导入回退，未纳入交付；保留失败样例用于后续后端工作。

R47：借助 R46 的浮点值传递支持，把 sincosf.c 的约简后多项式提取为
文件内 static、显式可重入 ABI4 函数 mcs251_sincos_poly(float f, float g)。
只在 __SDCC_mcs251 且 __SDCC_MCS251_NATIVE_RUNTIME 时启用；外部 sincosf
及 sinf/cosf 的 ABI、范围约简、YMAX、EPS2、符号和 errno 行为保持原样。
系数和表达式求值顺序未改，每次加法/乘法仍调用既有 binary32 运行库；
没有 FMA、硬件加速器、降低阶数、缩小定义域或放宽误差。
build_runtime.py 仅对 sincosf 增加 --mcs251-wide-backend：多项式进入宽 MIR，
外层保留原后端；仍是64个归档成员，只有 sincosf.rel 改变，其余63项相同。
两个 stack-auto 模型该成员均减少161B（1146->985、1173->1012）。
编译器二进制与R46相同。8种非native的MCS251/MCS51模型对象逐字节不变。
poly-oracle.json 使用独立精确有理数，host-oracle-validation.json 交叉核对
宿主浮点；两个模型共4096多项式逐位结果、4096正弦余弦与原版逐位/errno
对照及中断重入见R47实板记录。NaN的外层测试仅验证迁移前后行为保持，
不能当作新增三角函数NaN数学契约；errno仍是共享全局变量，不是线程局部。

R48：fsmul_fast.inc 是 native ABI4 正规乘法快路径的唯一汇编源码。
_fsmul.c 的 native 分支直接包含它；独立运行库构建器使用同一文件，
再拼接原 fsmul_bits.c 生成的回退核心，不再从旧轮次汇编截取快路径。
普通 MCS251 ABI 及 MCS51 分支保持原指令，未自动替换现有标准库。
按 ma=ah*256+al、mb=bh*256+bl 分拆 24 位尾数：
cross=ah*bl+al*bh+(al*bl>>8)，最大小于2^25；
hi=ah*bh+(cross>>8)，低16位非零条件为 (cross&255)|(al*bl&255)。
完整部分乘积的进位通过 DR 加法保留；仅当低16位不再影响高位时才合并sticky。
仍为三次16x16与一次8x8乘法，保持规范化及最近偶数舍入；舍入加128改为DR加法。
局部临时栈峰值仍为5字节(符号1字节及高部分乘积4字节)，不是总调用栈。
DR12压栈/DR0出栈与原四字节顺序等价，板上IRQ嵌套覆盖其保存/恢复。
正规输入、结果指数[1,253]守卫和所有特殊值/次正规数/溢出回退保持原样；
fallback生成对象逐字节不变。无精度、定义域、NaN载荷或有符号零的删减。
本轮编译器不变，仅两个stack-auto浮点归档的_fsmul.rel改变，1256->1161B。
独立有理数参考、低字节进位穷举、双模型实板边界与C251定向计时见R48报告。

R49：fsmul_fast.inc 将正规结果指数守卫改为16位WR运算。
先排除输入指数0/255；(ea+eb-128)按16位无符号比较小于253，恰好等价于
ea+eb-127处于[1,253]。比较通过后加1恢复原指数，不以8位回绕替代范围判断。
结果乘积的右移规范化改为两个SRL WR，再把高字移出的最低位补回低字最高位。
最低被丢弃位在移位前已经并入sticky，指数、RNE、最终打包和回退规则保持。
两个stack-auto模型的乘法成员1161->1136B，前缀272->247B；889B回退不变。
编译器/其余63个浮点归档成员/非native分支不变，临时栈峰值仍5B。
guard-identity.json覆盖65536指数对及393216跨字右移组合；exponent-board-results.json
记录两种固定尾数组合下全部指数对的逐项独立参考比较，不能称为穷举所有浮点输入。
正切模块ABI4指针探针仅用于确定后续迁移阻碍，没有并入运行库或烧录。
