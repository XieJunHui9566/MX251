# 分支条件驱动的常量传播

2026-11-10，基于 `23be706`，分支 `codex/branch-facts`。本轮扩展 MX251 的共享中端：从相等分支和 switch 的分派边获得确定值，重新计算此前保存的整数表达式，再交给现有常量折叠和死代码消除。普通后端和宽后端共同受益，没有修改 SDK 或按工程、函数名匹配。[构建与实板证据](branch-facts-evidence.json)记录冻结输入和产物指纹。

例如：

```c
ep = id & 15;
if (id == 0x81)
    flags &= ~(1u << ep);
```

旧版在分支内仍执行移位循环；新版沿相等边得到 `id=0x81`、`ep=1`，最终生成常量掩码。即使 `ep` 在分支之前计算，或两个不同条件都导出同一个掩码值，也能折叠。

## 完整工程

沿用冻结输入、small/speed、FunctionSharing、MachineIr、CalleePreservation、普通调用反馈和函数 GC；TFT、MSC 继续使用 NativeIntegerRuntime。CDC 的父版用上一轮冻结编译器重新构建。三个工程的源码指纹及工程配置均与各自父版相同。

| 工程 | 父版 / B | 本轮 / B | 变化 / B | Keil / B | 本轮 / Keil |
| --- | ---: | ---: | ---: | ---: | ---: |
| p080 TFT | 19683 | 19696 | +13 | 18071 | 108.99% |
| p087 USB CDC | 4517 | 4451 | −66 | 3531 | 126.05% |
| p091 USB MSC | 5559 | 5386 | −173 | 4401 | 122.38% |

MSC 距体积 120% 线还需减少 105 B，距 110% 线还需减少 545 B。TFT 仍低于体积 110% 线。三个工程均通过 `FINAL_ACTUAL_CALL_PRESERVATION_VERIFIED`。没有完整工程相对 Keil 的运行时间成绩。

MSC 的 `usb_get_status` 从 252→157 B、`usb_clear_feature` 从 187→150 B、`usb_set_feature` 从 181→140 B；CDC 对应三个函数分别减少 32、14、20 B。这些收益来自相同的中端规则。

TFT 应用函数的指令字节数没有变化。13 B 增量全部来自 `format-runtime.asm`：格式化输出的百分号分支获得字符常量 `0x25` 后，原来的公共尾部匹配位置改变，需要保留一份地址准备代码。本轮记录这一局部回退，没有加入按函数或工程关闭优化的特殊处理。

## 实现

`SDCCgenconstprop.cc` 在现有 CFG 分支传播后调用 `mcs251/branch_facts.cc.inc`，没有另建优化流水线。表达式关系按基本块计算，分支处保留可用关系；合流只保留所有可达前驱上相同且仍有效的定义。循环回边参与迭代，含单基本块回边；结果或输入被重新定义时，相应关系失效。自引用更新不能被解释为当前值之间的等式。

跟踪范围为不超过 32 位的整数临时值，以及未取地址的自动局部值/参数。直接全局对象、volatile 对象、地址逃逸对象不作为关系中的可变来源；一次读取形成的临时快照可以跟踪。内联汇编清除表达式关系。

相等分支（EQ 的真边或 NE 的假边）将一侧已知的常量传播到另一侧。跳表按独立边的序号确定分派索引，重复目标仍保留多条边并在目标处合流。复制、转换和常量加减可反向推导，但仅在来源当前范围内存在唯一原值时生效，因此 `(u8)word == 0x81` 不会把整个 `word` 错当成 `0x81`。这也覆盖了非零起点 switch 生成的减法归一化。

根据分支信息，复用现有类型转换、加减、位运算和移位的值域运算，反复收紧相关表达式。指令替换、剩余常量折叠与死代码消除仍由现有中端处理。环境变量 `MX251_BRANCH_FACTS=0` 可用于同一编译器的开关对照，默认开启。

同一份程序分别编译为 ordinary-wide 和 legacy 两个单元，使用独立符号，在同一固件内运行。64 个种子每个遍历 4 个字节输入，共覆盖 256 种字节值，并组合宽整数输入。Python 参考独立计算结果；没有以另一个编译后版本作为正确性分母。
