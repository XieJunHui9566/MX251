# 窄无符号取负的默认后端选择：2026-11-09

原宽后端已经能生成 8/16 位无符号取负，但只在试验开关下启用。波特率计算中的 `65536 - value` 被中端化成 16 位取负后，会让整个函数退回字节后端。本次复用已有发射能力，补上默认候选选择；SDK 源码和算术实现未改。

对普通 ABI2、没有循环、含窄无符号取负的函数，编译器生成宽后端和普通后端两份完整候选。宽候选体积更小且静态指令数不增加时采用它，否则采用普通后端。比较允许现有整数运行库调用，使用普通构建流程重新计算调用破坏集合。选择依据 IR 与完整候选，不含工程名或函数名特判。

既有线性/CFG 选择的成本覆盖范围保持原样。本次新增选择单独补齐 CJNE、ADDC、SUBB、RRC 的 Source 模式计价，包括经典寄存器指令的 A5 前缀。静态指令数是选择指标，不等同于实板耗时；函数含循环时沿用原路径。

`MX251_NARROW_UNSIGNED_NEGATE=0` 可恢复原默认行为；`=1` 保留此前强制试验含义。未设置时采用新选择，正常 CMake 工程无需添加开关。
