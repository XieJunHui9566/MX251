# 相同函数体共享：首轮完整工程结果

2026-11-09。本轮落实的编译器改动是将宽后端的参数容量从 8 扩到 16。ABI2 仍只有首参走寄存器，ABI4 仍为两个；栈参数的宽度、顺序、调用者清栈和返回值约定不变。超过 16 个参数仍采用原普通后端。

研究找到一个比近期局部改动更大的体积机会：TFT 的三个字体函数可以共享主体。**自动函数共享尚未实现**；下列共享结果来自独立源码副本，不能计入冻结 SDK 成绩，也不交付为 SDK 改写。原工程和原始工作目录保持原样。具体输入、镜像与检查记录见 [证据](function-sharing-evidence.json)。

## 完整镜像结果

| p080 TFT 配置 | 代码 / B | 相对原版 |
| --- | ---: | ---: |
| 冻结原输入、父版编译器 | 23153 | — |
| 仅将原 `_swap` 标为 inline 的副本 | 22938 | −215 |
| 共享字体主体的副本、父版编译器 | 22797 | −356 |
| 同一共享副本、16 参数编译器 | 22156 | −997（4.31%） |

两个源码试验彼此独立，未把节省相加。Keil 基线仍为 18071 B；22156 B 仍超过 120% 和 110% 体积线，没有整工程运行时间结果。

三个原字体函数的最终指令各为 648 B，仅常量、表地址和局部标签不同。试验保留原来的三个公开入口，将字体表、条目步长、条目数、边长和字模字节数作为共享函数的额外参数。循环、绘图调用、模式判断和颜色写入沿用原算法。

共享函数共有 11 个参数。父版在 `wide_stack_signature()` 的 8 参数容量处退出，三个包装函数也无法导入宽后端。共享主体为 1017 B、包装各 110 B，还引入了 `__mulint` 和 `__gptrget`。扩到 16 参数后，共享主体为 650 B、包装各 99 B，额外运行库调用消失。最终 997 B 的差额恰好对应原三个主体 1944 B 与新主体加包装 947 B 的差额。

这说明“抽出公共实现后仍能生成有效的原生代码”是需要保留的编译能力；不能把旧后端的容量退回误认为抽象本身必然昂贵。但容量扩展本身不会自动合并原 SDK 的三个函数。

## 本轮停止的小方向

- `_swap` 展开使 `Fill_Triangel` 从 1276 降到 1102 B，并移除 41 B 的辅助函数；其栈 MOV 静态字节从 288 增至 336，局部对象没有自动全面寄存器化。没有因此扩建指针辅助函数自动内联。
- 按现有寄存器效果摘要扫描基本块内的重复 MOV，四个代表工程仅发现 12、9、12、6 B。没有为这些字节增加后端 pass。该数值只描述这一扫描规则，不是所有复制优化的上限。
- 只忽略立即数和局部标签的完整机器指令形状分组，p080 找到三个字体函数，p095 找到两个 70 B 的端点函数，p087/p091 未找到 ≥40 B 的组。这还不能称为全部工程的共同收益。

## 编译器改动验证

[16 参数样例](../core/sources/compiler/src/mcs251/tests/wide-many-arguments.h)覆盖 8/16/32 位整数、负数和两个三字节指针。ABI2 检查 CODE/XDATA 指针，ABI4 沿用现有 XDATA 指针资格。small/large × ABI2/ABI4 四组都进入宽后端；ABI2 栈实参 36 B，ABI4 为 34 B，逐项入口偏移符合原布局。

[原栈参数回归](../core/sources/compiler/src/mcs251/tests/check-wide-stack-arguments.py)通过，包括四组模型/优化组合、17 参数回退和嵌套调用。旧测试要求 `high_pressure` 必须溢出，但父版已有整数下沉使其帧为零；父版与新版该编译单元的完整 REL 完全相同，因此移除这条过时要求，保留实际压力函数及取址对象检查。

实板使用 [专用工程](../core/sources/compiler/src/mcs251/tests/wide-many-arguments-hardware.json)，包含宽调用者→宽被调者、宽调用者→旧被调者、旧调用者→宽被调者三条路径。STC-Link1D 重新枚举后完成下载，AI8051U-34K64 的 UART 收到 2769 帧，覆盖 256 组输入，每组 3 次 16 参数调用，全部与[独立主机计算](../core/sources/compiler/src/mcs251/tests/check-many-arguments-capture.py)一致。设备保留本次测试固件。此实板结果验证参数传递，没有执行共享字体工程或测量其运行时间。
