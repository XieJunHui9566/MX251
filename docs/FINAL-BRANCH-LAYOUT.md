## 改动机制

`machine_branch.h` 复用机器指令解析器与已有 Source 模式编码长度接口。它在寄存器转发、死写消除后运行，缩短本函数内的 `EJMP`，消除跳到下一条指令的跳转，并将“条件跳过无条件跳转”合成一个短条件分支。持续缩短至不再变化，因此早先超出范围的分支也能受益。

范围直接按最终指令累计：向前最多 127 B，向后将新分支自身的 2 B 计入 128 B。未知编码阻止跨越该区间；外部目标保持原样。跳转表、内联汇编和原流水线排除的特殊入口继续沿用原路径。函数文本内重复的局部标签不参与变换。启用 `MachineIr` 时默认执行，可用 `MX251_FINAL_BRANCHES=0` 单独关闭分支整理。

另一个问题在机器流水线入口：旧后端的 `rbank` 是 `arN` 汇编别名发射状态，初始为 -1，不能代表宽后端当前函数的寄存器组。宽后端有意不修改该全局状态，原检查因而会跳过首个宽函数或此前留下其他寄存器组的函数。现在显式传入生成后端：宽代码按当前函数的寄存器组判断，字节后端仍检查它实际发射的别名状态。

仅分支整理时 TFT 为 19386 B；修正入口后为 19318 B。CDC 的波特率分发函数从 345 降至 297 B，状态查询从 226 降至 220 B；MSC 的 SCSI 分发从 422 降至 406 B。上述函数名仅用于结果归因，优化规则没有工程或符号名单。
