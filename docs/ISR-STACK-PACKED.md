## 三处衔接

1. ISR 保存分析复用公共指令效果，识别编译器产生的 `pushw` 字参数和 `inc/dec spx` 相对栈调整。参数压栈、调用、清栈都保留，只根据实际改写集合精简中断入口和出口的保存对。
2. 已识别的普通外设位操作不再阻止打包保存。它们不读取私有现场帧，因此可沿用原有 DR 打包布局；有局部 C 栈对象的 ISR 也可以打包，局部对象仍在完整现场帧上方。局部帧的保存删除限制保持不变。
3. 构建反馈收集含内联汇编 ISR 的直接调用，以便把被调函数的实际 GPR 改写集合交给编译器。ISR 本身仍不导出普通函数调用约定或改写承诺；包含未知内联指令的中断体继续使用原保存。只知道有调用和允许精简这个调用者，是两个不同步骤。

PSW1 仍首存末取，原 PSW 在切换 bank0 之前保存；GPR 恢复后再恢复 PSW。外设操作、实参顺序、调用和函数体访存没有重排。没有增加新的优化开关；`MX251_LEAF_ISR_SAVES=0` 关闭保存删除，已知位操作的完整打包布局仍可使用。
