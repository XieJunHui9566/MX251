# 固定数组基址的符号化索引访问（2026-11-16）

本批在 MX251 wide 后端保留全局/静态对象的符号地址，访存时结合已求值的整数下标生成地址，减少常量基址长期占用寄存器以及跨调用保存。实现不检查器件、SDK、工程编号或函数名，没有修改 SDK 源码。

## 调查与实现

复查 p106 后确认，上一批共享循环范围和整数缩窄已经消除了此前观察到的下标符号扩展。此次实际处理的是仍驻留 DR28 的 `_buf` 常量基址。

- 利用现有真实 CFG 支配分析，传播单一定义的对象地址、指针复制/转换及固定偏移。
- 对无符号 8/16 位动态下标，把符号和固定偏移放到原有内存节点中。支持 1/2/4 字节普通 RAM 访问，保留下标取值时机、访问位置和宽度。
- 低 16 位相加后，通过 CY 计算高 8 位并清零表示填充，覆盖跨 64 KiB 页的地址生成，不假定 XDATA 固定位于某一页。
- 移除不再使用的地址定义，重新分配寄存器；与原方案比较完整函数体积、加权指令成本、栈帧和现有循环成本。没有改动既有择优规则。
- 补齐 ADDC 立即数的字节成本及分支距离上界识别。
- 动态/分支合流指针、负下标、CODE、栈对象、指针对象和 volatile 字节访问沿用已有路径；已有 EDATA 符号索引路径继续使用。

残留下标复制另作检查，本次未找到可直接删除的死定义，未加入额外清理变换。

## 独立验证

- 新增独立数组/回调压力代码，覆盖字节读改写、16/32 位访问、固定偏移、分支合流、负下标、动态指针、volatile。调用的函数会改变数组内容，不能通过跨调用缓存数据得到错误收益。
- small/large × speed/size × ABI2/ABI4 共 8 种配置通过。关闭新变换后，指令文本与上一版一致；负下标、动态指针、分支指针和 volatile 控制函数指令保持一致。
- 独立访问编译单元：ABI2 为 1421→1375 B（减少 46 B），ABI4 为 1158→1110 B（减少 48 B），上述结果在两个模型和两种优化选项中一致。所有配置都覆盖实际采用的 1/2/4 字节访存路径。
- 对实际发射的 ADD/MOV/ADDC/MOVZ 地址序列运行独立寄存器/CY 模型，覆盖全部 16 位下标及多组页边界、24 位回绕地址，共 1,179,648 项通过。这是地址计算模型检查，不是整段固件运行证明。
- 171 项指令字节成本与实际汇编器编码长度一致，包括本次加入的 ADDC 和符号低字相加。
- 独立测试已生成 GCC 的 512 组参考值，构建 1942 B 测试固件；最终固件中 16/32 位访问确实采用新路径。
