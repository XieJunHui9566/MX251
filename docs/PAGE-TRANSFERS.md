# 链接后的页内短调用与短跳转

2026-11-13，实现提交 `e259285`，父版 `2c411da`，分支 `codex/page-transfers`。

## 实现

在已有同段近调用选择之后，依据最终链接地址，将可用的 `LCALL/LJMP` 缩成两字节 `ACALL/AJMP`。调用参数、两字节返回地址及 `RET` 保持原约定。SDK、算法和 C 源文件没有改变，选择规则不包含工程或函数名称。

布局计算先假设候选全部缩短，再剔除缩短后下一条指令与目标不在同一 2 KiB 页的候选；每次剔除后重新计算位移，直到集合稳定。最终只重新汇编相关单元并链接一次。链接后核对指令编码、实际目标、预测地址和全镜像字节差。此轮没有引入函数重排。

范围沿用上一轮近调用的入口分析及跳转表处理。变换位于连续的 CSEG；其他区段的引用交给链接器重定位。`near-transfers.json` 升级为 schema 2，新增 `pageTransfers`，总减少量包含近调用和页内短指令两阶段；`page-baseline/` 保存第二阶段之前的成品。`-NearTransfers OFF` 关闭整个转移优化。

## 汇编器修复

页内短调用实际使用后暴露两个问题：

- 可重定位段的本地偏移尚未包含链接基址。汇编阶段仅检查绝对段的页范围，可重定位段由链接器按最终地址检查。
- MCS251 的页内转移重定位记录需要 5 字节，原实现只预留 4 字节。混合记录恰好填满缓冲区时，会覆盖后续 T 记录的地址字节。现在按实际记录宽度预留。

原编译器驱动和链接器二进制保持相同；替换汇编器，并在现有启动运行库契约中登记其哈希。前一轮试编因尚未登记新汇编器而退回完整启动代码，保留为研究记录，不作为结果。

## 验证

- 6 项布局用例：下一条指令的页边界、跨页、缩短后进入同页、剔除候选引起另一次跨页、前后向目标及空集合。
- 12 份现有完整编码用例及 6 个实际链接用例通过；后者覆盖非页对齐的区段基址、合法跨局部页及非法跨最终页。
- 混合重定位记录用例在修复前汇编器上失败，在修复后通过。该用例覆盖本轮试编实际发现的地址覆盖问题。
- AI8051U 40 MHz，STC-Link1D 自动定位 COM13。夹具由多个翻译单元组成，间隔函数使代码跨越两页，包含 23 处 ACALL、4 处 AJMP，并保留 2 处跨页 LCALL。覆盖递归、局部数组、混合 ABI 和远调用。
- 两版各 128 个输入结果通过独立 Python 运算核对。父版 3012 B、新版 2985 B。两个工作负载的 64 输入中位数汇总为 16025→16024.5、8320→8320 ticks（Timer0 /12T）；没有据此认定运行速度提高。
