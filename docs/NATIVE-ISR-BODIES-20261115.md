# 通用 bank0 中断函数体接入宽后端

2026-11-15。源码提交 `b1560bd31eb02f39d1e051729cf6883c843743ed`，基于统一 203 工程矩阵的 `5b26ad7`。

本轮使普通 bank0、void、ABI2 中断函数可以使用已有宽后端的运算、寻址和寄存器分配。没有器件名、工程名或 SDK 函数名判断，也没有修改测试工程算法。先生成两个完整候选；宽候选的字节数严格减少且静态指令数不增加时才采用。无法完整计价或导入失败的函数继续使用旧后端。

中断入口先保存 PSW1，再保存 PSW 并切换到 bank0，随后保存通用寄存器和 DPX；所有 C 返回路径汇入共同恢复出口，最后执行 RETI。禁止套用普通函数的尾跳转。无局部帧的候选复用已有保存集合分析；存在局部帧、无法分析的间接写入或调用时保留完整现场。局部对象和溢出槽仍由 SPX 相对寻址。其他寄存器组、naked、critical 等入口继续沿用旧实现。编译器环境变量 `MX251_NATIVE_ISR=0` 可用于关闭新路径做对照。

与 [11 月 11 日原型](NATIVE-ISR-STUDY.md) 相比，当前宽后端已补齐更多通用能力。本次复用原型入口设计，并接入当前保存分析、机器指令处理及完整函数择优，没有直接采用旧原型的收益结论。
