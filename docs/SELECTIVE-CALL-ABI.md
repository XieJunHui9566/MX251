## 实现与使用

高频双整数参数函数即使内部还有其他调用，也可自动尝试寄存器传参。调用者与被调函数一同重编，整份固件更小时采用。原有 `SelectiveLeafAbi=AUTO` 选项名、receipt 字段和输出目录保留兼容；默认已启用，不需工程添加函数清单。

候选仍要求 ordinary-wide、stack-auto、standard runtime、普通 ABI2/bank0、唯一公开定义、无地址逃逸，所有入口均为有匹配类型的直接调用；启动、库、显式保留及 function-GC 根引用排除。两个整数参数可为 8/16/32 位，返回类型为 void 或相同整数类型集合。至少 16 个最终调用点，按调用数乘第二参数位宽排序，每次只试首个候选。

工程中的数值向量汇编通过已有 `Get-Mx251FormatRawVectors` 分析：跳转必须落入已登记的 C ISR 向量，且没有其他符号入口或普通指令。C 单元继续执行原有类型与引用检查。未登记的裸地址入口、项目归档、不透明或间接调用等条件沿用现有限制。

候选构建执行原有调用破坏反馈、函数 GC 和链接；最终 ABI4 定义及每个调用点绑定到 RST/HEX。向量单元没有 C 函数 ABI，绑定检查只读取 C 单元的编译器汇编。选择过程没有加入工程名、SDK 名或函数名规则。SDK 源码和编译器二进制均未修改。

## 独立执行验证

[独立夹具](../tools/research/automatic_call_abi_fixture.py)包含跨文件 32 次 `void(u8,u16)` 调用。被调函数再调用两次单字节处理函数，随后继续使用两个原参数；写入 volatile XDATA 字数组并计算摘要。主机独立计算 64 组预期值，另有 64 组既有控制程序。工程还包含一份已登记的数值中断向量汇编，用于覆盖混合输入的选择路径；此夹具不触发该中断。

AI8051U-34K64，40 MHz，Timer0 /12T，UART1 115200；自动定位 STC-Link1D（82941086）和 COM13。每个输入取多帧计时中位数后汇总：

| 项目 | 父版 | 新版 |
| --- | ---: | ---: |
| 固件体积/B | 2327 | 2200 |
| 测试组/tick | 53568 | 53440 |
| 控制组/tick | 10084.5 | 10083 |
| 正确摘要 | 128/128 | 128/128 |
| 完整帧 | 588 | 586 |

体积减少 **127 B（5.46%）**，测试组耗时减少 **0.24%**，控制组基本不变；所有采样均无计时溢出。板上保留新版夹具固件。这里的时间证据仅覆盖该独立工作负载。
