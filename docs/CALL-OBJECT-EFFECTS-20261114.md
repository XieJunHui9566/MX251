# EDATA 对象与 PSW 标志位的通用调用分析

实现提交：`afae2e16040f517fc869ac88a364168c91cd4a5c`。编译器 SHA-256：`dd5096ce9921a0f6d11675f16bf6e81cca4524e8cb3678177deb56940c208a06`。

编译器为实际分配的 EDATA 对象输出空间和长度，调用分析利用链接器已有的 [0x100, stackBase) 分配约束识别 e: 写入及符号地址；跨文件定义与同名 static 按原有绑定规则处理。PSW 的六个非银行选择位支持数字、声明别名及 PSW.bit 写法，RS0/RS1 和整字节 PSW 写入维持原处理。没有增加器件开关，也没有改动 SDK 源码或算法。

97 个可构建工程全部通过候选核心公开入口重编，同源配置逐字节核对。合计 277132 → 276674 B，减少 458 B；19 项缩小、78 项相同、0 项增大。

原调用分析阻塞的 27 个 ISR 中，本轮解开 15 个，剩余 12 个。USB 深层指针及间接跳转未扩大实现。

前期只按中断保存估计300 B；普通调用还受益于F0识别及EDATA信息：EEPROM/I²C调用减少现场保存，部分红外函数不再需要额外的函数入口保存。g123的SCSI普通调用减少7 B；g133的EEPROM、发送调用及布局合计减少62 B。这些变化来自同一通用分析，没有增加针对例程的优化。

所有ISR函数体在归一化调用/跳转宽度后与父版相同；本轮中断收益来自入口/出口保存缩减。普通函数还会重新分配跨调用活跃值，个别函数可略增大，工程总量均未增大。
