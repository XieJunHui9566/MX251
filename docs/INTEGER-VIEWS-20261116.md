# 等宽整数视图与对象访存信息（2026-11-16）

本批补齐两处通用语义信息，减少寄存器复制。14 个代表编译单元中 9 个缩小、5 个不变，合计减少 64 B；随后完整构建的三个工程共减少 46 B。收益有限，本方向在此收尾，不继续以零散复制消除作为下一轮主线。

## 实现

- 有符号/无符号整数的等宽转换共享存储值。每个使用点保留自己的符号性和宽度，扩展、比较和移位仍使用原有语义；布尔归一化继续作为独立操作。指针地址空间及浮点类型的匹配规则保持原有约束。
- 普通已分配 C 对象的访问，将既有对象来源信息传到最终机器指令层。对应 MOV 继续执行，优化器可以跨过它保留不受影响的寄存器等值关系。没有新增内存缓存或删除实际内存读写。
- 原始参数指针、绝对地址及来源未知的访问不产生该信息。支持间接地址上的数值偏移，寄存器合并时保留偏移。
- 诊断开关 `MX251_INTEGER_VIEW_COPIES=0`、`MX251_OBJECT_MEMORY_FACTS=0` 可分别关闭两处新能力。

实现不读取器件名、SDK 路径、工程编号或应用函数名，未修改 SDK 源码和目标描述。
