# 普通位返回调用：2026-11-09

宽后端原来遇到返回 `__bit` 的函数就退回字节后端，影响 Flash 读写和 USB 状态轮询。本次补齐普通 ABI2 的 CY 返回值接收，生产修改集中在 `wide.c` 和 `wide_emit.c.inc`，SDK 源码未改。

调用后用 `CLR A; RLC A` 把 CY 转为 0/1，随后写入分配好的寄存器或栈槽。取值发生在清栈前，避免 `SUB SPX` 改写 CY。未使用的返回值省去转换；CY 返回不能沿用 DPL 返回的直传优化。已有调用保存、函数成本选择及其他 ABI 沿用原实现。

## 完整工程收益

采用同一 EDATA 父版与候选，正常 CMake 入口、small/speed、函数 GC、C251 位补兼容，叶函数反馈选项保持默认关闭。原有调用破坏集合反馈由构建流程自动执行。

| 冻结工程 | 父版 / B | 候选 / B | 减少 / B |
| --- | ---: | ---: | ---: |
| p091 USB MSC | 6577 | 6421 | 156（2.37%） |
| p087 USB CDC | 4923 | 4923 | 0 |
| p095 USB/双串口 | 6782 | 6782 | 0 |
| p080 TFT | 23195 | 23195 | 0 |

p091 的 `flash_writesector` 为 430 → 352 B，`scsi_in` 为 265 → 203 B，`scsi_out` 为 226 → 155 B。其他调用者的保存代码也发生变化，最终净减少以完整 HEX 的 156 B 为准。

先前启用额外叶函数反馈的比较为 6621 → 6405 B（减少 216 B）；它属于另一组配置，不作为默认成绩。两组的输入哈希、编译器身份及构建记录均保留。

本次新增 120%/110% 体积达标工程为 0。p091 同模型 Keil 分母为 4401 B，当前约 145.9%；SDK 运行时间尚未测量。这项补齐有实际收益，但还不足以解决主线差距。

- 新增测试覆盖 small/large、speed/size、反馈开关共 8 组；包含 3/6 字节栈参数、CY 到字节、真实返回值溢出、未使用结果及关闭宽后端时的对象一致性。
- 28 组位操作/ABI、18 组普通调用和 8 组返回直传回归通过。返回直传旧测试仅识别 `SUB/ADD SPX`，已更新为同时核对现有 `DEC/INC SPX`，并比较父版和候选指令。
- 当前生产循环成本实现通过 V0.0136 负例检查。
