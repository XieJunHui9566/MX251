## 改动

- MDU 配置下，32 位十进制转换每一位只调用一次既有 `___m251r4__divulong`。用低字节恒等式 `r = (n - 10q) mod 256` 计算余数；由于完整余数在 0..9，该低字节就是完整余数。没有另一次求余或 32 位乘法。普通软件配置保留原来的逐位算法。
- 根据实际格式集合裁剪进制分支；字母大小写只从十六进制格式推导，移除不再使用的 flags 参数。16/32 位和 printf/sprintf 共用这一生成逻辑。
- 公开变参入口仅建立 va_list、调用普通内部函数并返回结果。格式解析循环进入宽后端；调用方 ABI、槽宽、格式串与返回长度保持一致。float 混合格式也使用相同入口。

没有工程名、文件名或 SDK 条件。MDU 使用条件取自项目已选择的运行库；没有新建硬件驱动或更改数学库 ABI。
