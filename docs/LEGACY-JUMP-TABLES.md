# 遗留后端跳转表与尾调用组

`genJumpTab` 现在为两种遗留跳转表发出描述信息，接入已有近调用与尾调用组选择器。C 编译器只增加汇编注释，不调整 switch 索引计算、参数传递或跳转指令；SDK 无需改动。

- 小表：`mx251-jump-table ... stride=4 dispatch=a-dptr` 描述 DPTR/DPXL 基址和 `jmp @a+dptr` 分发。选择器核对基址、表标号和 EJMP 槽位，保留每槽四字节，只缩短表外跳转与调用组成员的返回。
- 大表：`mx251-address-table ... low=... high=... ext=... entries=...` 描述三张地址字节表。选择器核对三次 MOVC、DPX 重组及 `ejmp @dr28`，确认各平面相同位置指向同一函数内的同一标号。已识别的 `.db` 表项不再阻断函数，三段地址继续由汇编器重定位。

宽指令后端已有的描述格式保持兼容。尾调用组仍统一选择调用与返回宽度；取地址、栈参数、未知间接跳转和其他汇编布局指令沿用既有处理。

验证包含 23 个尾调用组选择用例、16 个近转移选择用例、6 个页布局用例。新增实板固件强制使用遗留后端生成四项 EJMP 表和十七项地址字节表，由宽指令后端生成两个尾调用入口。检查最终 HEX 中的表项宽度和重定位目标，使用独立 Python 算法核对运行结果。
