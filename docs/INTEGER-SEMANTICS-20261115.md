# ABI无关整数语义：实现与实测（2026-11-15）

本批完成上一轮研究的第一优先级：有符号二次幂除法、16位来源的完整32位乘法。代码位于通用MCS251后端，运算身份取自编译器符号表和完整类型；没有工程号、函数名或器件判断，也没有修改SDK。循环范围分析留给下一批。

## 实现

- ABI2栈参数与ABI4寄存器参数进入同一算术参数视图。
- 对所有定义证明16位扩展来源，生成硬件16×16完整乘积，再按符号修正高字。仅供乘法使用的扩展临时值缩为16位；有其他用途的32位值保持完整。原取样位置和volatile事务次序保留。
- 有符号除以正的二次幂，负数先加偏置再算术移位，保持C的向零舍入。覆盖最小负数、非整除、跨字移位；16位以上移位只处理有效高字。负数余数与负除数沿用原路径。
- 补齐局部有符号条件跳转的指令效果摘要，使新增序列的寄存器读写可被调用保存分析使用。

p127的FFT内层消除4次长乘法、2次长除法调用。相关编译单元自身增加20 B，但完整链接不再需要263 B的有符号/无符号长除法实现，所以净减243 B。FFT栈帧由32 B增加到50 B；不能把这次改动说成已经改善寄存器分配或栈占用。

p140的ADC中消除1次长除法，其他位置仍使用除法库，完整固件增加11 B。该项是速度方向的改动，本轮没有取得体积改善。p135另外消除3次长乘法，完整结果见表。

已重放包含长乘除调用的22个编译单元，19个代码字节数不变，3个发生变化。共消除7个长乘法和3个长除法静态调用点。这里是针对本次算术库存的扫描，不是全203项的新统一矩阵；不更新全量110%/120%达标数量。Keil数据沿用已保存的对应工程参考，本轮没有重新构建Keil或STC-IDE。

## 独立用例与硬件

新增测试包含有符号/无符号/混合乘法、截断后乘法、共享扩展值、volatile先后取样、普通用户调用和未知完整32位运算。ABI2/ABI4、small/large、size/speed共8种组合通过；既有二次幂、范围除法、宽乘法和分支效果检查通过。

STC-Link1D自动定位到COM13。使用同一独立测试源，新版ABI4、新版ABI2及前版ABI4各通过704组结果校验，每组包含4个输入；参考值由固定宽度C类型的主机GCC程序独立计算。

| 独立测试 | 前版ticks | 本版ticks | 变化 |
| --- | ---: | ---: | ---: |
| 7种有符号常量除法组合 | 34684 | 7304 | -78.94% |
| 有符号/混合完整乘法组合 | 6194 | 5523 | -10.83% |
| 跨字大位移除法组合 | 11594 | 5904 | -49.08% |

计时包含分派和每种子4个输入的执行开销，没有计时器溢出。全部11类计时保存在JSON中：两类仍走独立小函数运行库调用的组合慢约1.5%和2.2%，不能宣称所有写法均加速。完整测试固件从2139 B增加到2171 B。

上述是独立内核计时，不是完整FFT/ADC工程的运行时间，也不是相对Keil的运行时间达标证明。
