## 实现

- 既有 ISR 保存精简器现在处理直接调用。复用被调用函数的实际 GPR 改写集合，移除未被中断函数及其调用闭包改写的保存对；支持八组 DR 与普通字节保存。DPX、PSW、位寄存器的调用效果尚未导出，因此有调用时继续保留这些现场。
- 间接读取区分地址寄存器的读取与数据目的寄存器的写入。间接写入接受编译器分配对象的完整平面指针来源，或已知且不落入核心寄存器区的 DPX 常量地址。普通对象、数组下标和外设状态读改写因此可以受益；指针收窄转换、任意指针和未知地址仍使用原保存。
- 普通 SFR 访问与有序内联汇编的许可分开处理：本优化不移动、删除或重排函数体外设访问。SP/PSW/PSW1、映射与执行控制写仍排除；补齐了 ACC 位及中断体内普通 PUSH/POP 的效果识别。
- 新增 `mx251-isr-call` 使用记录，接入最终调用效果验证与已有的写集合扩张修复。ISR 本身仍不导出普通调用约定。PSW1 始终首存末取，bank0 切换顺序不变。
- 本轮仍处理无局部栈帧的普通 bank0 C ISR；其他入口继续原路径。没有新增默认构建开关。
