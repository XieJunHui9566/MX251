## 实现

ISR 中的 `clr/setb/cpl 0xNN.bit` 现在按具体 SFR 字节及位掩码分析。已知外设位操作没有 GPR、DPX 或标志改写，因此可以与普通 C 指令一起计算中断实际需要保存的现场。`0x8f.4` 按 251 的 byte.bit 寻址解释，不套用经典 SBIT 编号的字节对齐规则。

完整内联汇编块在代码发射前分类，因为 `genInline` 随后会释放其文本；保存精简仍根据最终函数体指令求效果。允许块内出现多个位操作、注释及大小写形式，保持外设指令原位、原顺序。涉及核心寄存器、PSW、栈、映射或执行控制的位操作，以及其他汇编指令，继续使用原有保存方式。

纯外设位 ISR 可以删除 ACC/B、DPX、扩展寄存器和无用 bank0 切换；PSW1 仍然首存末取。混合 C 访存或已有调用反馈的 ISR 按原效果分析保留其实际改写部分。入口范围沿用无局部栈帧的普通 bank0 C ISR。

默认生效，沿用 `MX251_LEAF_ISR_SAVES=0` 研究关闭开关。没有工程名、函数名或 SDK 名称规则。
