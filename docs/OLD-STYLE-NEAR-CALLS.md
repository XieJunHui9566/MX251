# 旧式空参数声明的近调用信息

`void f()` 在 C11 声明中不指定参数数量。此前 `ordinaryScalarSignature` 排除所有无原型声明，导致实际无参数的函数不能参与近调用和页内调用选择。

本次在 AST 降低为 iCode 时记录调用表达式是否没有实参，并在复制 iCode 时保留这个事实。函数定义的参数列表为空、返回类型与调用属性符合原有约定时，发出 `mx251-near-definition`；对应的无实参调用发出 `mx251-near-call`。不满足实际参数条件的调用记录未知签名，使现有全程序选择器排除目标。仅在局部类型副本上规范化声明，不改变源类型、参数传递方式、标量传播或 ABI 选择。

选择仍要求所有引用都是兼容的直接调用。取地址、汇编入口、带参数的 K&R 定义等保留原方式。SDK、运行库及链接选择算法没有修改。

验证包含实际编译元数据检查、混合已知/未知调用的选择检查，以及跨翻译单元的 AI8051U 固件。固件覆盖 void、8/16/32 位返回、ABI2/ABI4、递归、局部数组、指针辅助函数与间接调用；128 个输入由独立 Python 算法核对。
