2026-11-13，实现 `2cef560`，分支 `codex/pointer-canonical-transport`。

统一 75 项体积结果：**75/75 ≤Keil 120%、66/75 ≤110%**。相对上一版，32 项缩小、43 项相同、0 项变大，净减少 **369 B**。p074 从 1015 降到 983 B，达到 Keil 的 **108.14%**，新增跨过 110% 线。

## 实现

研究见 [剩余地址优化](REMAINING-ADDRESS-RESEARCH.md)。改动沿用已有 MIR 与发射器接口：

- 三字节指针栈参数仍按一字节、两字节的顺序读取。`MOVZ` 已把四字节内部表示的最高字节清零，因此省掉随后重复的 `ANL`。寄存器结果直接装入最终分配位置；落栈结果保留存栈，只省掩码。
- `wide_loop_cursors` 已证明数组对象范围、循环私有地址及末次 one-past 值无人使用；现在通过 `boundedCursorStep` 把这一事实传到发射器，保留 32 位递增并省掉逐次掩码。

三字节 ABI、内存访问顺序和宽度沿用原实现。一般指针参数算术仍做 24 位规范化；整数到指针转换仍沿用原规则。直接装载使用既有的寄存器编码、活值重叠与栈槽检查。规则不涉及 SDK 名称、函数名称或特定算法，SDK 源输入未改。
