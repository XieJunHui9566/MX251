# DPX 调用效果与 ISR 地址复用

2026-11-13，分支 `codex/isr-dpx-call-effects`，实现 `f5e41f5`。以 `unified75-closure/core-switch-02` 为父版，统一重编全部 75 项：**75/75 ≤Keil 120%，64/75 ≤110%**。22 项缩小、53 项相同、0 项变大，共减少 **320 B**；合计 **192064 / 192049 B（100.01%）**。

输入、优化选项与父版一致。p108 保留双方已声明的单行汇编修复；Keil/STC 引用相同输入的既有结果。STC 仍为 59 项生成 HEX、13 项不支持汇编、3 项失败，仅作原始体积参考。没有改写 SDK C 文件或按工程、函数名选择优化。体积统计不代表完整工程运行时间已达标。

## 实现

- 构建反馈分别计算 DPTR 低 16 位和 DPXL 高字节的可能改写集合，沿直接调用、尾调用、递归和单元局部函数传播。未知定义及旧运行库摘要仍保留完整 DPX 效果。
- 新的 `MX251-CALL-CLOBBERS-3` 包含作用域、ABI、GPR 与 DPX 掩码；编译器继续接受 v1/v2。ISR 按实际需要省去 DPL/DPH/DPXL 保存对。每个省略点参与最终调用闭包核对；后续编译扩大 DPX 写集合时，原有反馈修复流程同步更新它。
- 原有常量 DPXL 复用扩展至 ISR，并允许跨过不修改 DPX 的符号立即数搬运。仍限定同一直线路径；分支入口、调用和未知写结束回溯。bank 0 平面写可能命中 DPXL 本身，不跨越这类写复用。
- ISR 地址分析同时识别前面已验证的间接写，以及已被新低地址覆盖的旧 DPTR 写，避免地址复用反过来阻断已有寄存器保存精简。

没有改变公开 ABI、向量、PSW/PSW1 保存规则或外设访问顺序。实现集中于后端和调用反馈。

## 验证

small/large × speed/size 下通过 40 项编译检查：16 个调用掩码、8 个旧格式对象对照、8 个直接地址别名、8 个地址复用场景。21 项指令效果、5 项跨函数闭包、22 项既有 CFG 地址和 74 项既有寄存器/运行库检查通过。专门模拟最终被调函数新增 DPXL 写，确认触发一次反馈修复，仍保留有效的 DPTR 保存省略。

AI8051U / STC-Link1D 实测两个固件，各 **128/128** 输入通过。Timer0/1 软件触发真实中断，覆盖四个寄存器组以及不改 DPX、只改 DPTR、只改 DPXL、改写完整 DPX；同时核对 R0..R31、DPX、PSW/PSW1、SPX 和计算/内存结果。完整 DPX 变体另覆盖 ISR 内保留高地址并连续访问。测试器的 Timer0/1 用于触发中断，串口记录中的 tick 不作为性能测量。板上保留最后下载的 split 固件。
